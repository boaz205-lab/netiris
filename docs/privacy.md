# Privacy Policy

Last updated: November 2026

NetIris is built with privacy in mind. This page explains plainly what information is collected when you visit this website.

What we do NOT collect

• No Cookies: We do not use tracking cookies, advertising cookies, or session cookies.
• No Accounts: You do not need to sign up, log in, or provide an email address to read our articles or view the dashboard.
• No Analytics: We do not use third-party analytics tools (like Google Analytics) to track your behavior, clicks, or location.

## What our hosting provider collects**

NetIris is hosted on GitHub Pages. Like all web hosts, GitHub automatically processes standard web server logs to keep the site running and secure.

When you visit the site, GitHub's servers may temporarily log standard technical information, such as:
• Your IP address (anonymized or kept briefly for security)
• The type of browser and device you are using
• The time and date of your visit
• The pages you requested

This data is processed by GitHub according to their own privacy policies. NetIris does not have access to this raw log data, nor do we use it to identify individual visitors. For more details, please read GitHub's Privacy Statement.

### Dashboard Data Privacy

The threat data shown on our Dashboard is strictly aggregated.
• We never publish raw IP addresses, URLs, or file hashes.
• We never publish data that can identify a specific individual or a specific victim's device.
• If a specific country or category has very few recorded events, we mark it as "low count" to prevent anyone from being identified through the data.

### Changes to this policy

Because this is a student project in active development, this privacy policy may be updated as we add new features. Any significant changes will be posted on this page with an updated date.
